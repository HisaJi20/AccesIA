# AccesIA

Sistema SaaS inteligente para la gestión de servicios de apoyo a personas con discapacidad visual.

## Descripción

AccesIA es una plataforma SaaS orientada a instituciones como municipalidades, ONG, universidades y centros de apoyo que brindan servicios a personas con discapacidad visual.

El sistema permitirá gestionar beneficiarios, servicios disponibles, solicitudes de asistencia, asignación de personal, seguimiento de atenciones, reportes, planes y suscripciones.

Como complemento, se integrará un asistente de Inteligencia Artificial mediante Ollama para orientar al beneficiario dentro de la plataforma y recomendar servicios de apoyo según su necesidad.
